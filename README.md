# SecureControls — validation build workspace

Working repository for standing up and market‑testing a **fixed‑price, artifact‑only managed NIST 800‑171 / SPRS compliance service for small defense subcontractors** (working name *SecureControls*; the brand is being finalized in the naming sprint).

The current focus is **validation**: prove the product, the market demand, and the feasibility — and get real market feedback fast — by building the assets needed to run the free‑assessment funnel against ~100–200 named prospects. Legal/entity/insurance, the full recurring system‑of‑record, the firm's own SOC 2, and the Phase‑2 enclave (*BeaconEnclave*) are intentionally deferred.
